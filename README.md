# 🌍 CO₂ Levels and Air Quality Forecasting Project

This repository contains a comprehensive data science project focused on analyzing historical atmospheric CO₂ levels and forecasting future trends using linear regression. The project also explores temperature datasets to provide a broader environmental context and gain deeper insights into air quality.

## 📁 Contents

- **CO2 levels.ipynb** – Exploratory data analysis and visualization of CO₂ concentration trends.
- **CO2 Predictions.ipynb** – Linear regression model to forecast CO₂ levels for the years 2025–2034.
- **air_quality.ipynb** – In-depth analysis of global, country, and city-level temperature data to understand environmental factors.
- **CO2_Analysis_Presentation.pptx** – A summary presentation of the project’s insights and results.
- **CO2_Analysis_Report.pdf** *(coming soon)* – The final project report with detailed findings and recommendations.

## 🧠 Key Highlights

- Analyzed monthly CO₂ data spanning multiple decades to understand long-term trends.
- Identified yearly and seasonal variations in CO₂ concentration.
- Engineered time-based features to enhance the forecasting model.
- Built a linear regression model to predict future CO₂ levels from 2025–2034.
- Visualized CO₂ trends and predictions with intuitive, interactive charts.
- Suggested future directions for deeper analysis using advanced time series models like ARIMA or LSTM for more accurate forecasting.
